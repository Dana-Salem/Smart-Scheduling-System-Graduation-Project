# Smart Scheduling System - Graduation Project

Smart Scheduling System is a graduation project developed to help university students generate suitable academic schedules based on their remaining courses, preferences, and academic constraints.

## Project Overview

The system helps students create conflict-free schedules by selecting courses and applying different preferences such as instructors, time range, break time, attendance days, and credit hours.

The system also includes AI-powered schedule ranking using Gemini API to help students compare generated schedules and choose the most suitable option.

## Main Features

- Student login
- Retrieve remaining courses
- Add courses before schedule generation
- Instructor preference selection
- Time range filtering
- Break time filtering
- Preferred attendance days selection
- Credit hours validation
- Conflict-free schedule generation
- AI-powered schedule ranking using Gemini API
- Favorite schedules
- Export selected schedule as PDF
